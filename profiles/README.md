# 👤 profiles/

This folder holds per-user diagnostic profiles and protocols generated by `/transmute`.

**Files in here are gitignored by default** (they contain personal info from the diagnostic interview). If you want to publish YOUR profile as a public example, remove the gitignore entry for that specific file.

Example structure:
```
profiles/
├── README.md                   # this file (tracked)
├── your-name.md                # diagnostic profile (gitignored)
├── your-name-protocol.md       # generated daily protocol (gitignored)
```
