# 🎯 Deep Work (Cal Newport)

## Core principle
**Cognitively demanding work in a state of distraction-free concentration produces value at an exponential rate vs shallow multitasking.** Discipline isn't grinding — it's protecting the conditions where deep work is possible.

```
SHALLOW WORK (most days)        DEEP WORK (rare, transformative)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━     ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Logistical, replicable        - Cognitively demanding
- Performed while distracted    - Distraction-free
- Easy to imitate               - Hard to replicate, high value
- Email, Slack, meetings        - Writing, coding hard problems,
                                  research, learning new skills
```

## How to use it
Block specific time windows for ONE hard task. No phone, no Slack, no tab-switching. The brain gets sharper at concentration the more you train it.

### Newport's Four Philosophies (pick what fits)
1. **Monastic** — long stretches of deep work, no shallow at all (writers, researchers)
2. **Bimodal** — alternating multi-day deep periods with shallow periods
3. **Rhythmic** — daily deep work block at the same time
4. **Journalistic** — fit deep work into any opening (advanced — hard to do well)

For most users: **Rhythmic** wins. Same time daily. The consistency builds the muscle.

## Rhythmic protocol template
```
Block: {EXACT TIME, e.g., 9:00am - 10:30am}
Task: {ONE specific hard problem — not a category}
Environment: {phone in another room, notifications off, doors closed}
Duration: 90 minutes (matches ultradian rhythm)
End: write 1 line about what you accomplished
Recovery: 15 min walk before any shallow work
```

## Use this framework when diagnosis shows:
- Performance diagnosis: keystone habit is cognitive (writing, coding, learning)
- Behavioral diagnosis: distraction is the failure point
- Biological diagnosis: attention span is fragmented

## Anti-patterns
- "I'll do deep work when I have time" → time never appears, schedule it
- 90 min with phone in pocket → not deep work, that's just sitting
- 4-hour blocks for beginners → fail. Start at 60-90 min.

## Connection to transmute
Deep work is the **vehicle** for the keystone habit identified by the performance coach. If your keystone is "write 500 words" or "build for 1 hour" or "study for 2 hours" — deep work is HOW you do it.

📚 Source: Newport, Cal. *Deep Work* (2016)
