# 🧱 Tiny Habits (BJ Fogg, Stanford Behavior Design Lab)

## Core formula
```
B = MAP
Behavior = Motivation × Ability × Prompt
```

If a behavior isn't happening, ONE of those three is too low. Usually it's Ability or Prompt — not Motivation.

## The Tiny Habits recipe

```
After I [EXISTING ANCHOR],
I will [TINY VERSION of new behavior],
then [CELEBRATION].
```

**Example:**
> After I pour my morning coffee,
> I will do 2 pushups,
> then say "I'm becoming someone who works out."

## Why it works
1. **Anchors solve the prompt problem** — the existing habit IS the trigger
2. **Tiny solves the ability problem** — 2 pushups requires no motivation
3. **Celebration solves the encoding problem** — emotion fixes the habit in memory

## Use this framework when diagnosis shows:
- Behavioral diagnosis: missing trigger/anchor in environment
- Behavioral diagnosis: friction is too high (target behavior too big)
- Performance diagnosis: keystone habit identified but not installed

## Recipe template for protocol generation
```markdown
### Daily Anchor: {behavior name}
After I {existing morning/evening routine step},
I will {smallest version of new behavior — must be doable in <60 sec},
then {celebration: fist pump, "yes!", smile, etc.}.

Frequency: every day, no exceptions
Failure recovery: NEVER chain 2 misses. Day 2 is mandatory regardless.
```

## Key rules from Fogg
- **Start ridiculously small.** "Floss one tooth" not "floss every night."
- **Anchor to a strong existing behavior.** Coffee, brushing teeth, sitting at desk.
- **Celebrate IMMEDIATELY.** The brain encodes habits via emotion within seconds.
- **Don't trust motivation.** Design as if you'll have ZERO motivation tomorrow.

## Anti-pattern
- Skipping celebration ("it feels silly") — DO IT ANYWAY, this is the encoding step
- Making it "tiny but still kind of big" — if it requires deciding, it's not tiny
- No anchor ("I'll just do it sometime in the morning") — without anchor, no trigger

📚 Source: Fogg, BJ. *Tiny Habits: The Small Changes That Change Everything* (2020)
